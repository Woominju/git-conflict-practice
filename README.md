# Conflict War – Team Adventure

Practice repository for Git collaboration workflows (January 2026).

## What I practiced
- Creating feature branches (`feature/alice`, `feature/bob`) for parallel work
- Producing and resolving a **merge conflict** on the same line of `story.txt`
- Undoing a bad commit safely with `git revert` instead of rewriting history
- Merging feature branches back into `main`

```text
Initial commit → Alice's / Bob's preference → Mistake → Revert "Mistake"
              → feature/alice, feature/bob → Merge branch 'feature/alice'
```
